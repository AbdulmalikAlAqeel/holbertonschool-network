# Networking basics #0

This project is part of the Holberton School curriculum, focusing on the fundamental concepts of computer networking, communication models, and core protocols.

## 📂 Project Tasks & Files

| Task File | Description |
| :--- | :--- |
| **`0-OSI_model`** | Answers regarding the OSI (Open Systems Interconnection) conceptual model and its layered architecture. |
| **`1-types_of_network`** | Answers covering LAN, WAN, and Internet concepts, usage, and geographical sizes. |
| **`2-mac_and_ip`** | Answers explaining MAC addresses, IP addresses, IPv4 vs. IPv6, public/private addresses, and localhost. |
| **`3-udp_and_tcp`** | Answers detailing the main data transfer protocols (TCP and UDP) and their key differences. |
| **`4-tcp_udp_ports`** | Answers covering network ports and standard port numbers (SSH, HTTP, HTTPS). |
| **`5-is_the_host_on_the_network`** | Answers regarding network diagnostics, ICMP, and the `ping` tool. |

## 🛠️ Requirements & Environment
* **OS:** Ubuntu 22.04
* **Editors:** `vi`, `vim`, `emacs`
* All answer files contain the number of the correct option followed by a new line.
